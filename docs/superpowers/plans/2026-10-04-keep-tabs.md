# Keep Tabs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let the user mark single tabs from the tab context menu so the tab-stash sweep never closes them, and show how many tabs are kept in the popup.

**Architecture:** A new pure module `extension/keep.js` stores a per-tab mark with the injected `browser.sessions` API (`setTabValue`/`getTabValue`/`removeTabValue`, key `"kept"`). The sweep flags tabs through `deps.withKeptFlag` before the synchronous, pure `selectTabsToStash`, which treats `tab.kept` as protected and leaves kept tabs out of the `maxTabs` count. `background.js` stays thin: it binds `browser.sessions` into `makeDeps`, registers a checkbox menu item, and answers a `kept-count` message for the popup.

**Tech Stack:** Firefox MV3 extension (plain ES modules, no bundler, event page), `browser.menus`, `browser.sessions`, vitest 4, web-ext.

**Spec:** `docs/superpowers/specs/2026-10-04-keep-tabs-design.md`

## Global Constraints

- Firefox MV3, `strict_min_version` stays `"140.0"`.
- `permissions` becomes exactly `["tabs", "alarms", "storage", "menus", "sessions"]`.
- Session key: `KEEP_KEY = "kept"`. A kept tab stores the value `true`; un-keeping removes the value.
- Menu item: `{ id: "pageslop-keep", type: "checkbox", contexts: ["tab"], title: "Keep tab (never auto-close)" }`.
- Popup text: `Kept tabs: N`.
- Message type: `{ type: "kept-count" }`.
- `selectTabsToStash` stays synchronous and pure. No in-memory cache of marks anywhere; the sweep reads marks fresh on every run.
- The popup's "Stash this tab" (`stashTab`) ignores the mark.
- No new npm dependencies. Never stage `package-lock.json`.
- Code style: tabs for indentation, double quotes, ES module `import`/`export`, one short comment above non-obvious functions, browser APIs injected (as `settings.js` takes `storage`).
- Tests: `npx vitest run tests/extension`. Full suite: `npx vitest run`. Extension lint: `npm run ext:lint` (baseline: 0 errors, 1 warning `KEY_FIREFOX_ANDROID_UNSUPPORTED_BY_MIN_VERSION`).
- Shell steps: one command per step line, no `&&` or `;`, no `cd`.
- Every commit message ends with the line `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>`.

## Review Focus

1. The `tab` object passed to `menus.onClicked` is a different object from the ones `tabs.query` returns, so "the clicked tab is in the selection" must compare by `id`, not by identity. Otherwise multi-selection silently never applies. Test: Task 1 (`targetTabs` with a fresh clicked-tab object).
2. A tab whose mark cannot be read (closed between `queryTabs` and `getTabValue`) must stay open, while the rest of the sweep still stashes and records success. Tests: Task 1 (`withKeptFlag` rejection) and Task 3 (sweep with a failing read).
3. A tab that is both pinned and kept must be left out of the `maxTabs` count once, not subtracted twice. Otherwise the cap pass closes too few tabs. Test: Task 2.
4. "Stash this tab" on a kept tab must still stash and close it, because an explicit user action wins. Test: Task 3 (`stashTab` on a kept tab).
5. If the background answers `kept-count` with something that is not a count (an error, or an older background without the handler), the popup must not print `Kept tabs: undefined`. Test: Task 5 (`describeKept`).

## Spec deviations and resolutions (read before Task 1)

- **Error reporting for unreadable marks.** The spec says the error "is reported through the existing `recordError` path". In the real code `recordError` writes `lastSweep = { stashed: 0, error }`, which the popup shows as "Last sweep failed", and `runSweep` then calls `recordSuccess`, which overwrites it. Following the spec literally would either be invisible or mislabel a successful sweep as failed. This plan logs the failure with `console.warn` inside `withKeptFlag` (the same channel the spec uses for "sessions unavailable"), leaves the tab open, and lets the sweep continue and record success.
- **`countKept` and failed reads.** "Number of tabs whose value is set": a failed read is not set, so `countKept` does not count it. `withKeptFlag` alone treats a failed read as kept (sweep fail-safe).
- **"Value is set"** means `getTabValue` resolved to something other than `undefined`.
- **"Logs one warning"** when sessions is unavailable means one `console.warn` per `withKeptFlag` call, not one per tab.
- **Menu checkbox state** in `onShown` uses `countKept(sessions, [tab]) > 0`, so an unreadable mark shows unchecked. Clicking it then sets the mark, which is the safe direction.
- **Popup fallback text.** The spec does not say what to show if the count is unavailable. This plan adds `describeKept(count)` to `extension/status.js`, which returns `Kept tabs: unknown` for anything that is not a non-negative integer.
- **Manifest test.** The plan adds `tests/extension/manifest.test.ts` so the permissions change has a failing test first.

```js
// Per-tab "keep" marks, stored with browser.sessions so they survive restarts
// and session restore. The sessions API is injected, as settings.js takes storage.

export const KEEP_KEY = "kept";

function messageOf(error) {
	return error instanceof Error ? error.message : String(error);
}

function hasSessions(sessions) {
	return typeof sessions?.getTabValue === "function";
}

// true or false, or null when the read failed (for example, the tab closed).
async function readMark(sessions, tabId) {
	try {
		return (await sessions.getTabValue(tabId, KEEP_KEY)) !== undefined;
	} catch (error) {
		console.warn(
			`Could not read the keep mark of tab ${tabId}: ${messageOf(error)}`,
		);
		return null;
	}
}

export async function setKept(sessions, tabIds, kept) {
	await Promise.all(
		tabIds.map((id) =>
			kept
				? sessions.setTabValue(id, KEEP_KEY, true)
				: sessions.removeTabValue(id, KEEP_KEY),
		),
	);
}

// Returns copies of `tabs` with `kept: boolean`. A mark that cannot be read
// counts as kept, so the sweep fails safe and leaves that tab open.
export async function withKeptFlag(sessions, tabs) {
	const list = Array.isArray(tabs) ? tabs : [];
	if (!hasSessions(sessions)) {
		console.warn("browser.sessions is unavailable; keep marks are ignored");
		return list.map((tab) => ({ ...tab, kept: false }));
	}
	const marks = await Promise.all(
		list.map((tab) => readMark(sessions, tab.id)),
	);
	return list.map((tab, i) => ({ ...tab, kept: marks[i] !== false }));
}

// Counts only marks that were read successfully.
export async function countKept(sessions, tabs) {
	const list = Array.isArray(tabs) ? tabs : [];
	if (!hasSessions(sessions)) return 0;
	const marks = await Promise.all(
		list.map((tab) => readMark(sessions, tab.id)),
	);
	return marks.filter((mark) => mark === true).length;
}

// The tabs a context-menu click applies to: the whole highlighted selection
// when the clicked tab is part of it, otherwise only the clicked tab.
export function targetTabs(clickedTab, highlightedTabs) {
	const list = Array.isArray(highlightedTabs) ? highlightedTabs : [];
	return list.some((tab) => tab.id === clickedTab.id) ? list : [clickedTab];
}
```

export function isProtected(tab, settings, origin) {
	if (tab.kept) return true;
	if (tab.pinned || tab.active || tab.audible || tab.incognito) return true;
	const url = parseUrl(tab.url);
	if (!url || (url.protocol !== "http:" && url.protocol !== "https:"))

	const host = url.hostname.toLowerCase();
	return settings.excludeDomains.some((domain) => hostMatches(host, domain));
}

// removeAll first keeps an update from leaving a duplicate item behind.
async function createMenus() {
	await browser.menus.removeAll();
	browser.menus.create({
		id: KEEP_MENU_ID,
		type: "checkbox",
		contexts: ["tab"],

browser.runtime.onInstalled.addListener(createMenus);

// Re-read the stored mark each time, so the checkbox also self-corrects
// after a failed write.
browser.menus.onShown.addListener(async (info, tab) => {
	if (!tab || !info.menuIds.includes(KEEP_MENU_ID)) return;
	try {
		const checked = (await countKept(browser.sessions, [tab])) > 0;
		await browser.menus.update(KEEP_MENU_ID, { checked });
		await browser.menus.refresh();
	} catch (error) {
		console.error("Could not show the keep mark", error);
	}
});

// A click applies to the whole highlighted selection when the clicked tab
// is part of it, otherwise only to the clicked tab.
browser.menus.onClicked.addListener(async (info, tab) => {
	if (info.menuItemId !== KEEP_MENU_ID || !tab) return;
	try {
		const highlighted = await browser.tabs.query({
			windowId: tab.windowId,
			highlighted: true,
		});
		const ids = targetTabs(tab, highlighted).map((t) => t.id);
		await setKept(browser.sessions, ids, info.checked);
	} catch (error) {
		console.error("Could not update the keep mark", error);
	}
});
