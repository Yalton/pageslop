**Interfaces:**
- Consumes: nothing from earlier tasks. These are pure ES modules with no browser APIs, so vitest imports them directly (`allowJs` is on in `tsconfig.json`, and vitest's `include` already covers `tests/**/*.test.ts`).
- Produces:
  - `DEFAULTS` (frozen object): `{ serverUrl: '', token: '', enabled: false, idleHours: 6, maxTabs: 25, excludeDomains: [], pausedUntil: 0, lastSweep: null }`
  - `normalizeSettings(raw: unknown): Settings`. It never throws. Every key comes back valid, and any invalid value becomes its default. `Settings` has exactly the `DEFAULTS` keys. `lastSweep` is `null | { at: number, stashed: number, error?: string }`.
  - `serverOrigin(serverUrl: string): string`. Returns the URL origin, or `''` when the URL is empty or invalid.
  - `loadSettings(storageArea): Promise<Settings>`. `storageArea` is `browser.storage.local` or a fake with `get(keys)` and `set(obj)`.
  - `saveSettings(storageArea, patch: object): Promise<Settings>`. Merges `patch` into the stored settings, normalizes the result, writes all of it back, and returns it.
  - `selectTabsToStash(tabs: Tab[], settings: object, now: number): Tab[]`. `Tab` is the `browser.tabs.Tab` shape: `{ id, windowId, url, title, pinned, active, audible, incognito, lastAccessed }`. It calls `normalizeSettings` itself, so raw stored settings are safe to pass in.
  - `isProtected(tab, settings: Settings, origin: string): boolean` and `hostMatches(host: string, domain: string): boolean`. Both are exported for the options-page preview and for tests.

**Decisions this task fixes (the spec leaves them open):**
- Numeric strings are accepted. `"12"` and `" 3 "` become `12` and `3`, and `"0.5"` becomes `0.5`, because the options page reads values from `<input>` elements as strings. Any other string (`"abc"`, `""`, `"1e3"`, `"-4"`) falls back to the default.
- `idleHours` must be finite, greater than 0 and at most 8760 (one year). Otherwise it is the default `6`. Fractional values are kept, since manual verification uses `0.02`.
- `maxTabs` is floored to an integer and must be between 1 and 10000. Otherwise it is the default `25`.
- `enabled` is true only for the boolean `true`. `"true"` and `1` count as false.
- `excludeDomains` accepts an array or a single string split on whitespace and commas (the options textarea). Each entry is lowercased, and any scheme, path, port, leading `*.` and leading or trailing dots are stripped. Empty entries are dropped and duplicates removed.
- `serverUrl` must parse as `http:` or `https:`, or it becomes `''`. It is stored as origin plus path with trailing slashes removed, which drops credentials, query and hash.
- The spec has no container rule and no "keep the last tab of a window" rule, so neither is implemented. Every window always keeps its active tab, because active tabs are protected.
- The 100-per-request limit is enforced by the sweep, which posts in batches (Task 14). `selectTabsToStash` returns every candidate.
- A tab with no numeric `lastAccessed` is treated as accessed at `now`. It is never idle, and it is the last choice in the cap pass.

```js
// Settings stored in browser.storage.local. Pure apart from the injected storage area.

export const DEFAULTS = Object.freeze({
  serverUrl: '',
  token: '',
  enabled: false,
  idleHours: 6,
  maxTabs: 25,
  excludeDomains: Object.freeze([]),
  pausedUntil: 0,
  lastSweep: null,
})

const MAX_IDLE_HOURS = 8760
const MAX_TABS_LIMIT = 10000
const NUMERIC_STRING = /^\s*\d+(\.\d+)?\s*$/

function isPlainObject(value) {
  return value !== null && typeof value === 'object' && !Array.isArray(value)
}

// Numbers pass through. Plain decimal strings like "12" or "0.5" are converted,
// because <input> values are strings. Anything else becomes NaN.
function toNumber(value) {
  if (typeof value === 'number') return value
  if (typeof value === 'string' && NUMERIC_STRING.test(value)) return Number(value)
  return Number.NaN
}

function normalizeIdleHours(value) {
  const n = toNumber(value)
  return Number.isFinite(n) && n > 0 && n <= MAX_IDLE_HOURS ? n : DEFAULTS.idleHours
}

function normalizeMaxTabs(value) {
  const n = Math.floor(toNumber(value))
  return Number.isFinite(n) && n >= 1 && n <= MAX_TABS_LIMIT ? n : DEFAULTS.maxTabs
}

function normalizeDomain(entry) {
  if (typeof entry !== 'string') return ''
  let d = entry.trim().toLowerCase()
  d = d.replace(/^[a-z][a-z0-9+.-]*:\/\//, '')
  d = d.split(/[/?#]/)[0]
  d = d.replace(/:\d+$/, '')
  d = d.replace(/^\*\./, '').replace(/^\.+/, '').replace(/\.+$/, '')
  return d
}

function normalizeDomains(value) {
  let entries
  if (Array.isArray(value)) entries = value
  else if (typeof value === 'string') entries = value.split(/[\s,]+/)
  else entries = []
  const out = []
  for (const entry of entries) {
    const d = normalizeDomain(entry)
    if (d !== '' && !out.includes(d)) out.push(d)
  }
  return out
}

function normalizeServerUrl(value) {
  if (typeof value !== 'string' || value.trim() === '') return ''
  let url
  try {
    url = new URL(value.trim())
  } catch {
    return ''
  }
  if (url.protocol !== 'http:' && url.protocol !== 'https:') return ''
  return (url.origin + url.pathname).replace(/\/+$/, '')
}

function normalizeLastSweep(value) {
  if (!isPlainObject(value)) return null
  if (!Number.isFinite(value.at) || !Number.isFinite(value.stashed)) return null
  const out = { at: value.at, stashed: value.stashed }
  if (typeof value.error === 'string' && value.error !== '') out.error = value.error
  return out
}

export function normalizeSettings(raw) {
  const src = isPlainObject(raw) ? raw : {}
  const pausedUntil = toNumber(src.pausedUntil)
  return {
    serverUrl: normalizeServerUrl(src.serverUrl),
    token: typeof src.token === 'string' ? src.token.trim() : '',
    enabled: src.enabled === true,
    idleHours: normalizeIdleHours(src.idleHours),
    maxTabs: normalizeMaxTabs(src.maxTabs),
    excludeDomains: normalizeDomains(src.excludeDomains),
    pausedUntil: Number.isFinite(pausedUntil) && pausedUntil >= 0 ? pausedUntil : 0,
    lastSweep: normalizeLastSweep(src.lastSweep),
  }
}

export function serverOrigin(serverUrl) {
  if (typeof serverUrl !== 'string' || serverUrl === '') return ''
  try {
    return new URL(serverUrl).origin
  } catch {
    return ''
  }
}

export async function loadSettings(storageArea) {
  return normalizeSettings(await storageArea.get(null))
}

export async function saveSettings(storageArea, patch) {
  const current = await loadSettings(storageArea)
  const next = normalizeSettings({ ...current, ...patch })
  await storageArea.set(next)
  return next
}
```

```js
// Pure tab selection. No browser APIs. See the spec section "Selection logic".
import { normalizeSettings, serverOrigin } from './settings.js'

const HOUR_MS = 3_600_000

export function hostMatches(host, domain) {
  return host === domain || host.endsWith(`.${domain}`)
}

function parseUrl(url) {
  if (typeof url !== 'string') return null
  try {
    return new URL(url)
  } catch {
    return null
  }
}

// `settings` must already be normalized. `origin` is the server origin, or ''.
export function isProtected(tab, settings, origin) {
  if (tab.pinned || tab.active || tab.audible || tab.incognito) return true
  const url = parseUrl(tab.url)
  if (!url || (url.protocol !== 'http:' && url.protocol !== 'https:')) return true
  if (origin !== '' && url.origin === origin) return true
  const host = url.hostname.toLowerCase()
  return settings.excludeDomains.some((domain) => hostMatches(host, domain))
}

export function selectTabsToStash(tabs, rawSettings, now) {
  const settings = normalizeSettings(rawSettings)
  const origin = serverOrigin(settings.serverUrl)
  const list = Array.isArray(tabs) ? tabs : []
  const lastOf = (tab) => (Number.isFinite(tab.lastAccessed) ? tab.lastAccessed : now)
  const byAge = (a, b) => lastOf(a) - lastOf(b)

  const candidates = list.filter((tab) => !isProtected(tab, settings, origin))

  // 1. Idle pass.
  const idleMs = settings.idleHours * HOUR_MS
  const selected = new Set(candidates.filter((tab) => now - lastOf(tab) > idleMs))

  // 2. Cap pass. Pinned tabs never count; idle-selected tabs are already leaving.
  let remaining = list.filter((tab) => !tab.pinned).length - selected.size
  const oldestFirst = candidates.filter((tab) => !selected.has(tab)).sort(byAge)
  for (const tab of oldestFirst) {
    if (remaining <= settings.maxTabs) break
    selected.add(tab)
    remaining -= 1
  }

  // 3. Oldest first.
  return [...selected].sort(byAge)
}
```

    - `ping(fetchFn, serverUrl, token): Promise<{ok: true, email: string} | {ok: false, error: string}>`

    - `ERROR_BADGE_COLOR = '#d32f2f'`
    - `runSweep(deps): Promise<{stashed: number, skipped?: 'busy' | 'unconfigured' | 'disabled' | 'paused'} | {error: string}>`
    - `stashTab(deps, tabId: number): Promise<{stashed: number} | {error: string}>` for the popup's "Stash this tab".
  - `deps` shape:

    | Key | Type | Notes |
    |---|---|---|
    | `queryTabs` | `() => Promise<Tab[]>` | `browser.tabs.query({})` |
    | `getTab` | `(id: number) => Promise<Tab>` | `browser.tabs.get`; may reject if the tab is gone |
    | `removeTabs` | `(ids: number[]) => Promise<void>` | `browser.tabs.remove` |
    | `fetch` | `(url, init) => Promise<Response>` | |
    | `getSettings` | `() => Promise<object>` | raw or normalized; the sweep normalizes |
    | `setBadge` | `(text: string, color?: string) => Promise<void>` | `''` clears the badge |
    | `recordError` | `(message: string) => Promise<void>` | persists `lastSweep = {at, stashed: 0, error}` |
    | `recordSuccess` | `(stashed: number) => Promise<void>` | **addition:** persists `lastSweep = {at, stashed}` |
    | `now` | `() => number` | epoch milliseconds |
    | `force` | `boolean \| undefined` | **addition:** manual "Stash idle now" skips the `enabled` and `pausedUntil` checks, but still needs a server URL and token |

  - Runtime messages handled by `background.js`: `{ type: 'sweep-now' }` resolves to the `runSweep` result, and `{ type: 'stash-tab', tabId: number }` resolves to the `stashTab` result.

**Behavior this task fixes:**
- `runSweep` returns `{stashed: 0, skipped}` instead of running when the sweep is busy, unconfigured, disabled or paused. These are a superset of `{stashed: number}`, so callers that only read `stashed` still work.
- Selected tabs are posted in batches of `BATCH_SIZE`. After each successful batch, the sweep re-reads each tab of that batch with `getTab` and closes it only if its current URL is in that batch's `saved`. If the tab has meanwhile become active or pinned, it stays open as well. Tabs that no longer exist are skipped.
- On a network error, a non-2xx status, a 401, a non-JSON body (for example, an HTML login page after a redirect) or a body without a string array `saved`, the failing batch closes nothing. The badge is set to `!` in `ERROR_BADGE_COLOR`, `recordError` is called, and `{error}` is returned. Earlier batches in the same sweep were already confirmed and closed, which is allowed: every closed tab was confirmed by the server.
- On success the badge is cleared and `recordSuccess(stashed)` is called, even when nothing was selected.
- Several selected tabs sharing one saved URL all close. Unselected tabs (for example the active tab) with the same URL are left alone.
- A module-level lock prevents overlapping sweeps.
- An unexpected exception (from storage, for example) takes the same error path.

```js
// Thin fetch wrappers for the pageslop stash API. fetchFn is injected for tests.

export const BATCH_SIZE = 100

const UNAUTHORIZED = 'Unauthorized (401): the token is missing, wrong or revoked'

export function apiUrl(serverUrl, path) {
  return serverUrl.replace(/\/+$/, '') + path
}

function messageOf(error) {
  return error instanceof Error ? error.message : String(error)
}

async function request(fetchFn, url, init) {
  let res
  try {
    res = await fetchFn(url, init)
  } catch (error) {
    return { ok: false, error: `Network error: ${messageOf(error)}` }
  }
  if (res.status === 401) return { ok: false, error: UNAUTHORIZED }
  if (!res.ok) return { ok: false, error: `Server returned ${res.status}` }
  try {
    return { ok: true, body: await res.json() }
  } catch {
    return { ok: false, error: 'Invalid response from server (not JSON)' }
  }
}

export async function postStash(fetchFn, serverUrl, token, tabs) {
  const result = await request(fetchFn, apiUrl(serverUrl, '/api/stash'), {
    method: 'POST',
    headers: { 'Content-Type': 'application/json', Authorization: `Bearer ${token}` },
    body: JSON.stringify({ tabs }),
  })
  if (!result.ok) return result
  const saved = result.body?.saved
  if (!Array.isArray(saved) || !saved.every((url) => typeof url === 'string')) {
    return { ok: false, error: 'Invalid response from server (no saved list)' }
  }
  return { ok: true, saved }
}

export async function ping(fetchFn, serverUrl, token) {
  const result = await request(fetchFn, apiUrl(serverUrl, '/api/stash/ping'), {
    headers: { Authorization: `Bearer ${token}` },
  })
  if (!result.ok) return result
  const email = result.body?.user?.email
  if (result.body?.ok !== true || typeof email !== 'string') {
    return { ok: false, error: 'Invalid response from server' }
  }
  return { ok: true, email }
}
```

```js
// Sweep orchestration. Every browser API arrives through `deps`, so this module is unit-testable.
import { BATCH_SIZE, postStash } from './api.js'
import { selectTabsToStash } from './select-tabs.js'
import { normalizeSettings } from './settings.js'

export const ERROR_BADGE_COLOR = '#d32f2f'

let running = false

function isHttpUrl(url) {
  try {
    const { protocol } = new URL(url)
    return protocol === 'http:' || protocol === 'https:'
  } catch {
    return false
  }
}

function messageOf(error) {
  return error instanceof Error ? error.message : String(error)
}

function toPayload(tab, closedAt) {
  const item = { url: tab.url, closedAt }
  if (typeof tab.title === 'string' && tab.title !== '') item.title = tab.title
  return item
}

async function fail(deps, message) {
  try {
    await deps.setBadge('!', ERROR_BADGE_COLOR)
  } catch {
    // The badge is cosmetic. Never let it hide the real error.
  }
  try {
    await deps.recordError(message)
  } catch {
    // Same for persistence of the error.
  }
  return { error: message }
}

// Re-read each tab and close it only if its CURRENT url was saved.
async function closeConfirmed(deps, batch, saved, requireInactive) {
  const savedUrls = new Set(saved)
  const ids = []
  for (const tab of batch) {
    let current
    try {
      current = await deps.getTab(tab.id)
    } catch {
      continue
    }
    if (!current || !savedUrls.has(current.url)) continue
    if (requireInactive && (current.active || current.pinned)) continue
    ids.push(tab.id)
  }
  if (ids.length > 0) await deps.removeTabs(ids)
  return ids.length
}

async function stashInBatches(deps, settings, tabs, requireInactive) {
  const closedAt = new Date(deps.now()).toISOString()
  let closed = 0
  for (let i = 0; i < tabs.length; i += BATCH_SIZE) {
    const batch = tabs.slice(i, i + BATCH_SIZE)
    const payload = batch.map((tab) => toPayload(tab, closedAt))
    const result = await postStash(deps.fetch, settings.serverUrl, settings.token, payload)
    if (!result.ok) return { closed, error: result.error }
    closed += await closeConfirmed(deps, batch, result.saved, requireInactive)
  }
  return { closed }
}

export async function runSweep(deps) {
  if (running) return { stashed: 0, skipped: 'busy' }
  running = true
  try {
    const settings = normalizeSettings(await deps.getSettings())
    const now = deps.now()
    if (settings.serverUrl === '' || settings.token === '') return { stashed: 0, skipped: 'unconfigured' }
    if (!deps.force && !settings.enabled) return { stashed: 0, skipped: 'disabled' }
    if (!deps.force && now < settings.pausedUntil) return { stashed: 0, skipped: 'paused' }

    const tabs = await deps.queryTabs()
    const selected = selectTabsToStash(tabs, settings, now)
    const result = await stashInBatches(deps, settings, selected, true)
    if (result.error) return await fail(deps, result.error)

    await deps.setBadge('')
    await deps.recordSuccess(result.closed)
    return { stashed: result.closed }
  } catch (error) {
    return await fail(deps, `Sweep failed: ${messageOf(error)}`)
  } finally {
    running = false
  }
}

// "Stash this tab" from the popup: protections are bypassed except http/https.
export async function stashTab(deps, tabId) {
  try {
    const settings = normalizeSettings(await deps.getSettings())
    if (settings.serverUrl === '' || settings.token === '') {
      return { error: 'Set the server URL and token in Options first' }
    }
    const tab = await deps.getTab(tabId)
    if (!tab || !isHttpUrl(tab.url)) return { error: 'Only http and https pages can be stashed' }
    const result = await stashInBatches(deps, settings, [tab], false)
    if (result.error) return await fail(deps, result.error)
    await deps.setBadge('')
    return { stashed: result.closed }
  } catch (error) {
    return await fail(deps, `Stash failed: ${messageOf(error)}`)
  }
}
```

```js
// Background event page (MV3, ES module). Wires browser APIs into sweep.js.
import { loadSettings, saveSettings } from './settings.js'
import { runSweep, stashTab } from './sweep.js'

const ALARM_NAME = 'pageslop-sweep'
const SWEEP_PERIOD_MINUTES = 5
const storage = browser.storage.local

function makeDeps(extra = {}) {
  return {
    queryTabs: () => browser.tabs.query({}),
    getTab: (id) => browser.tabs.get(id),
    removeTabs: (ids) => browser.tabs.remove(ids),
    fetch: (url, init) => fetch(url, init),
    getSettings: () => loadSettings(storage),
    setBadge: async (text, color) => {
      await browser.action.setBadgeText({ text })
      if (color) await browser.action.setBadgeBackgroundColor({ color })
    },
    recordError: async (message) => {
      await saveSettings(storage, { lastSweep: { at: Date.now(), stashed: 0, error: message } })
    },
    recordSuccess: async (stashed) => {
      await saveSettings(storage, { lastSweep: { at: Date.now(), stashed } })
    },
    now: () => Date.now(),
    ...extra,
  }
}

// Create the alarm only if it is missing. Re-creating it on every wake-up
// of the event page would keep resetting the 5-minute timer.
async function ensureAlarm() {
  const existing = await browser.alarms.get(ALARM_NAME)
  if (!existing) browser.alarms.create(ALARM_NAME, { periodInMinutes: SWEEP_PERIOD_MINUTES })
}

browser.runtime.onInstalled.addListener(ensureAlarm)
browser.runtime.onStartup.addListener(ensureAlarm)
ensureAlarm()

browser.alarms.onAlarm.addListener((alarm) => {
  if (alarm.name === ALARM_NAME) runSweep(makeDeps())
})

// Returning a Promise from onMessage sends its value back to the sender.
browser.runtime.onMessage.addListener((message) => {
  if (!message || typeof message !== 'object') return undefined
  if (message.type === 'sweep-now') return runSweep(makeDeps({ force: true }))
  if (message.type === 'stash-tab' && Number.isInteger(message.tabId)) {
    return stashTab(makeDeps(), message.tabId)
  }
  return undefined
})
```

```js
// Pure text helpers for the popup.

const MINUTE_MS = 60_000
const HOUR_MS = 3_600_000
const DAY_MS = 86_400_000

const SKIP_MESSAGES = {
  busy: 'A sweep is already running',
  unconfigured: 'Set the server URL and token in Options first',
  disabled: 'Auto-close is off',
  paused: 'Paused',
}

function plural(n, word) {
  return `${n} ${word}${n === 1 ? '' : 's'}`
}

export function timeAgo(at, now) {
  const diff = Math.max(0, now - at)
  if (diff < MINUTE_MS) return 'just now'
  if (diff < HOUR_MS) return `${Math.floor(diff / MINUTE_MS)} min ago`
  if (diff < DAY_MS) return `${Math.floor(diff / HOUR_MS)} h ago`
  return `${Math.floor(diff / DAY_MS)} d ago`
}

export function describeLastSweep(lastSweep, now) {
  if (!lastSweep) return 'No sweep yet'
  const ago = timeAgo(lastSweep.at, now)
  if (lastSweep.error) return `Last sweep failed ${ago}: ${lastSweep.error}`
  if (lastSweep.stashed === 0) return `Last sweep ${ago}: nothing to stash`
  return `Last sweep ${ago}: stashed ${plural(lastSweep.stashed, 'tab')}`
}

export function describeResult(result) {
  if (!result || typeof result !== 'object') return 'No response from the extension background'
  if (typeof result.error === 'string') return `Failed: ${result.error}`
  if (result.skipped && SKIP_MESSAGES[result.skipped]) return SKIP_MESSAGES[result.skipped]
  if (result.stashed === 0) return 'Nothing to stash'
  return `Stashed ${plural(result.stashed, 'tab')}`
}

export function isPaused(settings, now) {
  return settings.pausedUntil > now
}

export function nextPausedUntil(settings, now) {
  return isPaused(settings, now) ? 0 : now + HOUR_MS
}
```

```js
})

$('open-revisit').addEventListener('click', async () => {

  await browser.tabs.create({ url: apiUrl(settings.serverUrl, '/dashboard/revisit') })
  window.close()
})

  await browser.runtime.openOptionsPage()
  window.close()
```

`extension/options.js`:

```js
import { ping } from './api.js'
import { selectTabsToStash } from './select-tabs.js'
import { loadSettings, normalizeSettings, saveSettings, serverOrigin } from './settings.js'

const storage = browser.storage.local
const $ = (id) => document.getElementById(id)
const fetchFn = (url, init) => fetch(url, init)

function fillForm(settings) {
  $('serverUrl').value = settings.serverUrl
  $('token').value = settings.token
  $('idleHours').value = String(settings.idleHours)
  $('maxTabs').value = String(settings.maxTabs)
  $('excludeDomains').value = settings.excludeDomains.join('\n')
  $('enabled').checked = settings.enabled
}

// Raw strings on purpose: normalizeSettings converts "6" to 6 and splits the textarea.
function readForm() {
  return {
    serverUrl: $('serverUrl').value,
    token: $('token').value,
    idleHours: $('idleHours').value,
    maxTabs: $('maxTabs').value,
    excludeDomains: $('excludeDomains').value,
    enabled: $('enabled').checked,
  }
}

function setConnected(ok) {
  $('enabled').disabled = !ok
  $('enabled-hint').hidden = ok
}

// permissions.request() only works during a user gesture, so this must be called
// synchronously from a click handler, before anything is awaited.
function requestHostPermission(origin) {
  if (origin === '') return Promise.resolve(false)
  return browser.permissions.request({ origins: [`${origin}/*`] })
}

async function showPing(form) {
  const result = await ping(fetchFn, form.serverUrl, form.token)
  setConnected(result.ok)
  $('ping-result').textContent = result.ok ? `✓ Connected as ${result.email}` : `✗ ${result.error}`
}

async function testConnection(form, permission) {
  $('ping-result').textContent = 'Testing…'
  if (form.serverUrl === '') {
    setConnected(false)
    $('ping-result').textContent = '✗ Enter a valid http(s) server URL'
    return
  }
  if (!(await permission)) {
    setConnected(false)
    $('ping-result').textContent = '✗ Permission to reach the server was not granted'
    return
  }
  if (form.token === '') {
    setConnected(false)
    $('ping-result').textContent = '✗ Enter an API token'
    return
  }
  await showPing(form)
}

async function save(raw, permission) {
  const granted = await permission
  const saved = await saveSettings(storage, raw)
  fillForm(saved)
  $('save-result').textContent = granted
    ? 'Saved'
    : 'Saved, but permission to reach the server was not granted. Sweeps will fail until you allow it.'
}

$('test').addEventListener('click', () => {
  const form = normalizeSettings(readForm())
  const permission = requestHostPermission(serverOrigin(form.serverUrl))
  testConnection(form, permission)
})

$('save').addEventListener('click', () => {
  const raw = readForm()
  const origin = serverOrigin(normalizeSettings(raw).serverUrl)
  const permission = origin === '' ? Promise.resolve(true) : requestHostPermission(origin)
  save(raw, permission)
})

$('preview').addEventListener('click', async () => {
  const stored = await loadSettings(storage)
  const settings = normalizeSettings({ ...stored, ...readForm() })
  const tabs = await browser.tabs.query({})
  const selected = selectTabsToStash(tabs, settings, Date.now())
  const list = $('preview-list')
  list.replaceChildren()
  if (selected.length === 0) {
    const item = document.createElement('li')
    item.textContent = 'The next sweep would close nothing.'
    list.append(item)
    return
  }
  for (const tab of selected) {
    const item = document.createElement('li')
    item.textContent = tab.title ? `${tab.title} (${tab.url})` : tab.url
    list.append(item)
  }
})

async function init() {
  const settings = await loadSettings(storage)
  fillForm(settings)
  setConnected(false)
  const origin = serverOrigin(settings.serverUrl)
  if (origin === '' || settings.token === '') return
  // No user gesture here, so only check for an existing grant; never request one.
  if (await browser.permissions.contains({ origins: [`${origin}/*`] })) await showPing(settings)
}

init()
```

The auto-close checkbox stays disabled until a ping succeeds, either from "Test connection" or from the automatic ping on load when permission was already granted. A disabled checkbox keeps its stored `checked` value, so saving while disconnected does not silently turn auto-close off. All tab titles and URLs are inserted with `textContent`, never `innerHTML`.

````markdown
## Browser extension

The Firefox extension in `extension/` closes idle tabs and saves them to the **To Revisit** inbox of your Pageslop instance. A tab is closed only after the server confirms it saved that URL. If the server is unreachable, nothing closes and the toolbar badge shows a red `!`.

### Connect it

1. In Pageslop, open **Settings → Browser extension**, enter a name such as "Firefox laptop" and create a token. Copy it right away: the token is shown only once. Revoke it from the same card at any time.
2. Load the extension (see below), open its **Options** page, and enter your server URL (for example `https://pageslop.example.com`) and the token.
3. Click **Test connection**. Firefox asks for permission to access your server. Grant it. You should see ✓ with your account email.
4. Set the idle hours (default 6), the maximum number of open tabs (default 25) and any domains that must never close, then enable **Auto-close idle tabs** and save. Use **Preview next sweep** to see what would close.

Pinned, active, audible and private-window tabs, non-http pages and your Pageslop server's own pages are never closed. Sweeps run every 5 minutes. The popup can also stash on demand, stash the current tab, pause for an hour, or exclude the current domain. Stashed items you don't act on are archived after `STASH_EXPIRE_DAYS` days (default 14). Nothing is deleted.

### Development

```bash
npm run ext:run    # launches a temporary Firefox profile with the extension loaded
npm run ext:lint   # web-ext lint
npm run ext:build  # zip in web-ext-artifacts/
```

You can also load it into your normal Firefox from `about:debugging` → **This Firefox** → **Load Temporary Add-on…** by selecting `extension/manifest.json`. Temporary add-ons are removed when Firefox restarts.

### Permanent install

Release Firefox only installs signed add-ons permanently. Submit the zip from `npm run ext:build` to [addons.mozilla.org](https://addons.mozilla.org/developers/) as an **unlisted** add-on. Signing is free and automatic, and unlisted add-ons are not shown publicly. Alternatively, sign from the command line with your AMO API credentials:

```bash
npx web-ext sign --source-dir extension --channel unlisted --api-key "$AMO_JWT_ISSUER" --api-secret "$AMO_JWT_SECRET"
```

Install the signed `.xpi` it produces by opening it in Firefox.

### Self-hosting

Each Pageslop instance belongs to a single owner. The extension talks only to the server URL you configure, and it asks for host permission for that origin alone. To run your own: deploy Pageslop, create your account, then set `ALLOW_SIGNUP=false` so nobody else can sign up, and point the extension at your instance.
````
