  <action>
    Create `src/components/graph/ForceGraph.tsx` (`'use client'`).

    This file is ONLY imported via dynamic() so `window` access is safe.

    Import: `ForceGraph2D` from `react-force-graph-2d`, `useRef`, `useCallback`, `useState`, `useMemo`, `useEffect` from React, `useLinks` from `@/lib/hooks/useLinks`, `LinkDetail` from `@/components/links/LinkDetail`, `GraphControls` from `./GraphControls`, `buildGraphData`, `crossLinkNodes`, `CATEGORY_COLORS`, `NODE_BASE_RADIUS`, `NODE_TAG_SCALE` from `./graphUtils`, types `GraphNode`, `GraphLink`, `GraphData` from `./graphUtils`, `LinkWithTags`, `Link` from `@/types`.

    Component structure:
    - Call `useLinks()` to get `links`, `isLoading`, `deleteLink`, `undoDelete`, `mutate`.
    - State: `visibleCategories: Set<string>` (empty = show all), `selectedLink: LinkWithTags | null`, `hoverNode: GraphNode | null`.
    - Use `useRef` for `highlightNodes: Set<GraphNode>` and `highlightLinks: Set<GraphLink>` — store in refs to avoid re-renders that restart simulation (per research Pitfall 5). Use a `renderTick` state counter incremented to trigger re-render when highlight refs change.
    - Use `useRef` for the ForceGraph2D instance (`graphRef`).
    - `graphData` via `useMemo` keyed on `[links, visibleCategories]`: call `buildGraphData(links, visibleCategories)`, then call `crossLinkNodes(result)` on the result, return it.

    CRITICAL — crossLinkNodes is safe to call here in useMemo (before d3 init):
    crossLinkNodes builds an internal nodeMap from data.nodes, then resolves the STRING IDs in each GraphLink.source/target to actual GraphNode object references via that map. After crossLinkNodes returns, node.neighbors[] contains real GraphNode objects — NOT strings. This means highlightNodes.has(neighborNode) works correctly by object identity when checking hover highlights, because the same GraphNode objects that live in data.nodes also live in each node's neighbors[].

    useMemo deps must use the links array reference from SWR, not a derived value — this prevents simulation restarts on unrelated state changes.

    Favicon image cache:
    - Module-level `const imageCache = new Map<string, HTMLImageElement>()` OUTSIDE the component.
    - `getImage(src: string): HTMLImageElement | null` — checks cache, creates `new Image()`, sets onload to cache, returns null until loaded.

    Dark mode detection:
    - Read `document.documentElement.classList.contains('dark')` inside a `useMemo` or on mount. Use it to set `backgroundColor` prop on ForceGraph2D. Light mode: `'#ffffff'`, dark mode: `'#09090b'` (zinc-950 from Tailwind, matching the app's dark bg).

    `handleNodeHover` callback (useCallback):
    - Build new `Set<GraphNode>` and `Set<GraphLink>` for highlighted elements. If node is not null, add node, add all node.neighbors (these are real GraphNode objects thanks to crossLinkNodes' nodeMap resolution), add all node.connectedLinks. Store in `highlightNodesRef.current` and `highlightLinksRef.current`. Set `hoverNode` state. Increment `renderTick` to force re-render.
    - Hover highlighting relies on Set.has() with object identity — this works because crossLinkNodes populated neighbors[] with the SAME GraphNode objects that are in data.nodes[].

    `handleNodeClick` callback: set `selectedLink` to `node.link`.

    `handleNodeDragEnd` callback: pin node with `node.fx = node.x; node.fy = node.y`.

    `paintNode` callback (useCallback, deps: [hoverNode, renderTick]):
    - Read `highlightNodesRef.current` for current highlight state.
    - Compute radius: `NODE_BASE_RADIUS + node.link.tags.length * NODE_TAG_SCALE`.
    - Determine color from `CATEGORY_COLORS[node.link.category ?? 'Other'] ?? '#6b7280'`.
    - If highlights are active (set not empty) and this node is NOT highlighted, append `'44'` to color hex for transparency.
    - Draw filled circle at (node.x, node.y) with radius r.
    - If `globalScale > 0.5` and node has favicon: get cached image, if loaded: save ctx, create circular clip path, drawImage centered, restore ctx.
    - If no favicon or not loaded: draw a letter initial (first char of domain or URL) in white, centered.
    - If `hoverNode === node`: draw label (link.title or link.url truncated to 40 chars) below the node in white text, font size scaled by `12 / globalScale`.

    `nodePointerAreaPaint` callback: draw a slightly larger circle (radius + 2) for hit detection.

    `linkWidth` accessor: if highlights are empty or link is highlighted, return `Math.min(1 + link.sharedTagCount, 4)`, else `0.3`.

    `linkColor` accessor: if highlights are empty or link is highlighted, return `'rgba(150,150,150,0.6)'`, else `'rgba(150,150,150,0.05)'`.

    `onToggleCategory` callback: toggle category in/out of `visibleCategories` set (create new Set for state update).

    `onEngineStop` callback: call `graphRef.current?.zoomToFit(400, 80)` to fit the graph in view after layout stabilizes.

    ForceGraph2D props:
    - `ref={graphRef}`, `graphData={graphData}`, `nodeId="id"`, `width` and `height` from a container ref using ResizeObserver or `window.innerWidth`/`window.innerHeight` minus sidebar width.
    - `nodeCanvasObject={paintNode}`, `nodeCanvasObjectMode={() => 'replace'}`, `nodePointerAreaPaint={...}`
    - `linkWidth`, `linkColor` as above
    - `onNodeClick={handleNodeClick}`, `onNodeHover={handleNodeHover}`, `onNodeDragEnd={handleNodeDragEnd}`
    - `warmupTicks={100}`, `cooldownTicks={300}`, `d3AlphaDecay={0.02}`, `d3VelocityDecay={0.4}`
    - `onEngineStop={onEngineStop}`
    - `enableNodeDrag`, `enableZoomInteraction`, `minZoom={0.1}`, `maxZoom={8}`
    - `backgroundColor` based on dark mode detection

    Layout:
    - Outer div `className="flex flex-col h-full w-full"`.
    - GraphControls at the top with visibleCategories, onToggleCategory, totalNodes, totalEdges from graphData.
    - ForceGraph2D fills the remaining space. Use a container div with `ref` and `flex-1` class. Track container dimensions via ResizeObserver (useEffect with cleanup) and pass width/height to ForceGraph2D.
    - LinkDetail rendered at the bottom of the component tree (it's a Dialog/Sheet, so position doesn't matter). Pass `selectedLink`, `open={!!selectedLink}`, `onClose={() => setSelectedLink(null)}`, `onDelete={deleteLink}`, `onUndoDelete={undoDelete}`, `onMutate={mutate}`.

    Empty state: If links is empty and not loading, show a centered message: "No links yet. Save some links to see your connection graph." with a muted color.

    Loading state: If isLoading, show a centered spinner or "Loading links..." text.

    IMPORTANT anti-patterns to avoid (from research):
    - Do NOT call `new Image()` inside paintNode — use the module-level imageCache Map
    - Do NOT recreate graphData on every render — useMemo keyed on [links, visibleCategories]
    - Do NOT use setState inside nodeCanvasObject — use refs for highlight state, trigger re-render via a counter
