       - Import decryptApiKey from '../lib/enrichment/crypto' (RELATIVE import — worker uses relative paths, NOT @/ alias)

       - If llmResult is not null, use it as the enrichment result
       - If llmResult is null, log warning and fall back to rule-based enrich()

    3. If no encryptedApiKey, use rule-based enrich() as before (no change to existing fallback path)
