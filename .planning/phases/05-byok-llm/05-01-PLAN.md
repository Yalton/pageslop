    2. Create src/app/api/settings/api-key/route.ts implementing:

       POST handler:
       - Get session (401 if none)
       - Parse body with { apiKey: string } — validate non-empty (400 if missing)
       - Call validateApiKey(apiKey) — returns false → 400 { error: 'Invalid API key...' }
         Differentiate: catch SDK error status to return "Key is valid but your Anthropic account has no credits" (403) vs "Invalid API key" (401 from Anthropic). If validateApiKey cannot differentiate, return generic "Invalid or unauthorized API key" message.
       - Call encryptApiKey(apiKey) → encrypted string
       - Call setEncryptedApiKey(session.user.id, encrypted)
       - Call maskApiKey(apiKey) → masked
       - Return 200 { maskedKey: masked, message: 'API key saved' }

       GET handler:
       - Get session (401 if none)
       - Call getEncryptedApiKey(session.user.id) → encrypted | null
       - If null → 200 { hasKey: false }
       - If encrypted → decryptApiKey(encrypted) → plaintext → maskApiKey(plaintext) → masked
       - Return 200 { hasKey: true, maskedKey: masked }
       - NEVER return the full plaintext key

       DELETE handler:
       - Get session (401 if none)
       - Call clearEncryptedApiKey(session.user.id)
       - Return 200 { message: 'API key removed' }

       Follow existing route pattern: import auth from @/lib/auth/server, headers from next/headers.
