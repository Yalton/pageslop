## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, tag pill internal padding |
| sm | 8px | Compact element spacing, card content gaps, list row padding |
| md | 16px | Default element spacing, card padding, form field gaps |
| lg | 24px | Section padding, sidebar group spacing |
| xl | 32px | Layout gaps between major areas (sidebar-to-content) |
| 2xl | 48px | Page section breaks, marketing page section spacing |
| 3xl | 64px | Marketing hero vertical padding |

Exceptions:
- FAB (mobile): 56px diameter (14 * 4) for comfortable touch target
- Sidebar width: 240px expanded, 64px collapsed
- URL input bar height: 48px (comfortable paste target)
- Link card image hero: 160px height in grid view
- Link card minimum width: 280px in grid view

### Accent Reserved For (explicit list)

The violet accent color is used ONLY on these elements:

1. **Primary action buttons** — "Save Link" submit, "Create Account" submit, "Log In" submit
2. **FAB (mobile)** — floating action button background
3. **Active sidebar nav item** — background highlight on current page
4. **Pending state indicator** — shimmer animation accent pulse on skeleton cards
5. **Toggle active state** — grid/list view toggle selected indicator
6. **Link hover** — link card border on hover
7. **Theme toggle icon** — sun/moon icon fill

Accent is NOT used on: body text, card backgrounds, sidebar background, headings, borders at rest, or icons at rest.

## Interaction Contracts

### Skeleton Shimmer Animation

- CSS `@keyframes shimmer` using a gradient sweep: transparent -> 10% white opacity -> transparent
- Animation duration: 1.5 seconds, `infinite`, `ease-in-out`
- Applied to Skeleton components inside pending LinkCards
- Shimmer direction: left-to-right sweep
- Background: `var(--muted)` with shimmer overlay

### View Toggle (Grid/List)

- Default: Grid view
- Toggle persists in `localStorage` key: `pageslop-view-mode`
- Transition: instant swap, no animation between views
- Grid: `auto-fill, minmax(280px, 1fr)`, gap 16px
- List: full-width rows, gap 0 (border separators)

### Link Save Flow

1. User types/pastes URL -> input border transitions to accent on focus
2. User submits -> button shows loading spinner (replace icon with spinner)
3. API returns 202 -> toast "Link saved" appears, new card prepended to grid in pending/skeleton state
4. SWR polls every 2s -> skeleton fills in as title, image arrive
5. All pending resolved -> SWR polling stops

### Duplicate Detection Flow

1. API returns `duplicate: true` -> toast appears: "This link is already saved"
2. Toast includes action button: "Save Again"
3. If user clicks "Save Again" -> POST with `force: true` -> normal save flow
4. If toast dismissed -> no action taken

### Delete Flow

1. User opens card actions menu -> clicks "Delete"
2. Confirmation toast: "Link deleted" with "Undo" action button (5 second window)
3. Card removed optimistically from UI immediately
4. If "Undo" clicked within 5s -> card restored, DELETE cancelled
5. After 5s -> DELETE request fires, permanent removal

### Sidebar Navigation

- Desktop: always visible, 240px width
- Mobile: hidden by default, triggered by hamburger icon in top bar, opens as Sheet (left slide)
- Nav items: All Links, Tags (disabled/grayed in Phase 1), Graph (disabled in Phase 1), Settings (disabled in Phase 1)
- Active item: violet background highlight
- Logout button: bottom of sidebar, ghost style, with `LogOut` Lucide icon

### Responsive Breakpoints

| Breakpoint | Width | Layout Changes |
|------------|-------|----------------|
| Mobile | < 768px | Sidebar hidden (Sheet), FAB visible, single-column grid, URL bar hidden (use FAB) |
| Tablet | 768px - 1024px | Sidebar collapsed (64px icons only), grid 2 columns, URL bar visible |
| Desktop | > 1024px | Sidebar expanded (240px), grid auto-fill, URL bar visible |

## Accessibility Contracts

| Requirement | Implementation |
|-------------|----------------|
| Keyboard navigation | All interactive elements focusable via Tab. Enter/Space to activate. Escape closes dialogs/sheets/dropdowns. |
| Focus visible | 2px violet outline ring on all focusable elements (shadcn default `ring-ring`) |
| Color contrast | All text meets WCAG AA (4.5:1 body, 3:1 large text) against their backgrounds |
| Screen reader | All images have `alt` text (title or empty string for decorative). Skeleton states have `aria-busy="true"`. Toast announcements via `aria-live="polite"`. |
| Reduced motion | Skeleton shimmer respects `prefers-reduced-motion: reduce` — disable animation |
| Touch targets | Minimum 44px touch target on mobile for all interactive elements. FAB is 56px. |
