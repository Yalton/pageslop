  <name>Task 2: Worker monitor-sweep cron and per-link monitor handler</name>
  <files>src/workers/scrape.worker.ts</files>
  <action>
1. Add imports at top of `src/workers/scrape.worker.ts`:
   - `import { checkUrl } from '../lib/monitor/check-url'` (relative import — worker uses relative, not @/ alias)
   - Note: updateUptimeStatus uses `@/lib/db/client` which won't work in the worker (worker has its own db). Instead, inline the update logic directly in the worker using the worker's local `db` instance, same pattern as the existing enrich handler. Import `links` from schema is already available.

2. In `main()`, after existing `createQueue` calls, add:
   ```
   await boss.createQueue('monitor-sweep')
   await boss.createQueue('monitor')
   ```
   Update the console.log to include monitor queues.

3. Register the 24-hour cron schedule (safe to call on every restart — pg-boss upserts):
   ```
   await boss.schedule('monitor-sweep', '0 2 * * *', {}, { tz: 'UTC' })
   ```

4. Add monitor-sweep handler — fans out individual per-link monitor jobs:
   - `boss.work('monitor-sweep', { localConcurrency: 1 }, async ([_job]) => { ... })`
   - Query all links with `status = 'ready'` using direct SQL on the worker's local `db`: `db.select({ id: schema.links.id }).from(schema.links).where(eq(schema.links.status, 'ready'))`
   - Batch insert individual `monitor` jobs using `boss.insert('monitor', batch.map(...))` with staggered `startAfter` (10 seconds per 100 links)
   - Log count of links enqueued

5. Add per-link monitor handler:
   - `boss.work<{ linkId: string }>('monitor', { localConcurrency: 20 }, async ([job]) => { ... })`
   - Extract `linkId` from `job.data!`
   - Fetch link URL: `db.select({ url: schema.links.url }).from(schema.links).where(eq(schema.links.id, linkId)).limit(1)`
   - If no link found, return early (link was deleted)
   - Call `const result = await checkUrl(link.url)`
   - Inline the updateUptimeStatus logic using the worker's local `db`:
     - If `result.up`: update with uptimeStatus='up', lastStatusCode=result.statusCode, lastCheckedAt=new Date(), consecutiveFailures=0
     - If `!result.up`: update with atomic `sql\`${schema.links.consecutiveFailures} + 1\``, lastStatusCode, lastCheckedAt, and `uptimeStatus: sql\`CASE WHEN ${schema.links.consecutiveFailures} + 1 >= 2 THEN 'down' ELSE ${schema.links.uptimeStatus} END\``
   - Log result: `[worker] monitor ${linkId}: ${result.up ? 'up' : 'down'} (${result.statusCode})`
  </action>
