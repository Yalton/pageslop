1. Create `src/lib/monitor/check-url.ts`:
   - Export `async function checkUrl(url: string): Promise<{ statusCode: number | null; up: boolean }>`
   - Use native `fetch` with `method: 'HEAD'`, `signal: controller.signal`, `redirect: 'follow'`
   - Set `AbortController` with `setTimeout(() => controller.abort(), 10_000)` for 10-second timeout
   - On success: `return { statusCode: response.status, up: response.status < 400 }`
   - On 405 status: retry with `method: 'GET'` (same timeout pattern, new AbortController)
   - On catch (AbortError or network error): `return { statusCode: null, up: false }`
   - Always `clearTimeout(timeoutId)` in both success and error paths

2. Create `src/lib/monitor/uptime.ts`:
   - Export `async function updateUptimeStatus(linkId: string, up: boolean, statusCode: number | null): Promise<void>`
   - Import `db` from `@/lib/db/client`, `links` from `@/lib/db/schema`, `eq` and `sql` from `drizzle-orm`
   - If `up === true`: update with `uptimeStatus: 'up'`, `lastStatusCode: statusCode`, `lastCheckedAt: new Date()`, `consecutiveFailures: 0`, `updatedAt: new Date()`
   - If `up === false`: update with atomic `consecutiveFailures: sql\`${links.consecutiveFailures} + 1\``, `lastStatusCode: statusCode`, `lastCheckedAt: new Date()`, `uptimeStatus: sql\`CASE WHEN ${links.consecutiveFailures} + 1 >= 2 THEN 'down' ELSE ${links.uptimeStatus} END\``, `updatedAt: new Date()`
   - Both branches: `.where(eq(links.id, linkId))`

3. Add `listLinksForMonitor` query to `src/lib/db/queries/links.ts`:
   - Export `async function listLinksForMonitor(): Promise<{ id: string; url: string }[]>`
   - Select only `id` and `url` from links where `status = 'ready'` (skip pending/error links per anti-pattern guidance)
   - No user filter — sweep checks all users' links

4. Run tests — all should pass GREEN.
